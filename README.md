# Voice Atelier Song Studio v0.3.3 — Melody Atelier連携と15分音声取り込み

iPad Safari向け、無料のボーカル録音・構成・ミックスWebアプリ。Netlify不要。保存データはIndexedDB（その端末・そのブラウザーの同じURL）に置き、アプリから外部に歌声を送信しません。

## トラック追加と「録り直し」（v0.3.3）

- タイムラインの各トラックの **「＋」** を押すと、すぐ下に新しい声レイヤーを挿入します。見出し側だけでなく、**タイムライン最下部の「＋ トラックを追加」** や録音画面の「＋ 声のレイヤーを追加」からも追加できます。追加直後は新レイヤーが録音先になります。最大24本。
- 録音モードに **「録り直し」** を追加。選択した **ブロック × 声レイヤー** に属する旧テイク全体をミュートにして、今回の新テイクへ切り替えます。古いWAVは消さず、録音エラー時は元の歌声をそのまま保持します。録り直した時間だけ差し替える「上書き」と異なり、録り直しはブロック内の旧テイクがまるごと再生されなくなります。
- 「↶ 直前の録音変更を戻す」は、上書きだけでなく録り直しでも機能します。元のテイクのミュート状態を復元し、新テイクをミュートします。取り消し履歴はプロジェクトZIPにも保存され、旧v0.3.2のバックアップとも互換性があります。
- **重要：** 旧テイクを復元できるのはアプリの変更履歴が保持されている間です。削除した音声そのものは復元できません。削除の前には必ずZIPバックアップを作ってください。

## 録音方法の切り替え（v0.3.3）

録音パネルの「録音方法」で「重ね録り／上書き／録り直し」を選択できます。初期設定は従来どおり重ね録りです。

- **重ね録り**：選んだ声レイヤーに、新しい音声クリップを追加して以前の声と混ぜます。
- **上書き**：同じ声レイヤーの今回の録音時間と重なった範囲だけ、古い音声の再生を抑止します。開始前や録音終了後の声は残ります。以前の原音WAVは一切書き換えず、取り消し用の範囲情報をプロジェクト内に保存します。
- **直前の上書きを戻す**：直前の操作で隠した範囲を復元し、新録音のクリップをミュートします。以前の声を消しません（直前の上書き最大20回分の履歴を保持）。
- 録音中の「他の声を聴く」を有効にしていても、上書き対象の声レイヤーは録音モニターから外し、ほかのレイヤーは再生します。
- 直前に上書きした新テイクを削除すると、その上書き範囲は自動復元します。古い上書きテイクを後で削除する場合は別の上書き履歴との競合を避けるため自動復元されません。「直前の上書きを戻す」を早めに利用してください。既存データの喪失防止のため、更新前・編集後はプロジェクトZIPバックアップを保存してください。
- 元録音クリップにできた斜線表示は、上書きにより再生しない区間です。元のファイルはそのまま保持されています。

## Melody Atelierとの連携

1. **まず現在の曲を「↓ プロジェクト一式ZIPで保存」でバックアップ**。連携読み込みは今の曲を置き換えます。
2. Melody Atelier **v0.4.0以降**で「↗ Voice Atelierへ渡すZIP」を使って連携用ZIPを作ります。
3. このアプリのタイムラインにある **「↗ Melody連携ZIPを取り込む」** から、連携ZIPを選択し、確認に同意します。
4. 歌詞、曲名、ブロック構成と開始位置、BPM、拍子が同期。メロディーガイドが「♪ メロディーガイド」という専用レイヤーに取り込まれます。
5. 他の声レイヤーでハモリやリードを録音。再生時はガイドと一緒に聴けます。
6. 完成WAVの書き出しは通常 **ガイドを含めず歌声だけ**。ガイド込みにする場合は「ガイド音声も完成WAVに混ぜる」をONにします。バックアップZIPにはガイドも含まれます。

**制約**：メロディーガイドは音声であり、このアプリで1音ずつ編集する機能はありません。編集はMelody Atelierで行い、再び連携ZIPを書き出してください。その際はVoiceで歌声ZIPをバックアップし、Voice側の連携読み込みが既存録音を置き換えることに注意してください。今のバージョンは既存の歌声を保持したまま新しいガイドだけを再同期する機能はありません。

## 音声時間とファイル形式

- **通常の音声ファイル取り込み：最大15分（1ファイル200MB以内）。** 対応コーデックはSafariが解読できる音声形式に依存します。音声ファイルは選択したブロック/声レイヤーに追加。
- **連携メロディーガイド：最大15分、WAV（200MB以内）、連携ZIP全体230MB以内。**
- **録音：1テイク最大3分（従来通り）。** 区間別の録音はブロック終了時に自動停止も可能。
- **曲全体の書き出し：最大15分、24bit WAV（44.1kHz等、利用端末のAudioContextサンプルレート）。**
- 4つの初期声レイヤーと追加声レイヤー、最大24レイヤー／160クリップ（設定上の数値でありiPadで安定動作する保証はありません）。
- **プロジェクトZIP復元：最大650MB。** プロジェクトに複数の長尺録音がある場合、バックアップ・復元はブラウザーのメモリや容量の制約を受けることがあります。

**品質と保存の注意**：長尺WAVのデコード、エフェクト、書き出しは大きなメモリを使用します。15分すべてをiPad実機で録音・再生・書き出しできることは現時点で未検証です。書き出し前にプロジェクトZIPを保存し、端末の空き容量を十分確保してください。高品質録音はマイク、環境、端末のサンプリング設定にも左右されます。

## 導入・更新（Netlify不要）

GitHub Pagesの公開リポジトリ `Voice-Atelier-Song-Studio` にZIP**内の** `index.html`, `app.js`, `styles.css`, `capture-worklet.js`, `sw.js`, `manifest.webmanifest`, `icon.svg` を配置。更新前は必ずプロジェクトZIPをバックアップしてください。GitHubに公開されるのはソースファイルで、録音や歌詞は明示的にアップロードしない限り公開されません。同じURLなら端末の自動保存を引き継ぐ設計です。初回HTTPS接続時はネット環境が必要です。

左側の歌詞パネルと右側の録音/ミックスパネルは独立スクロールに対応しています。iPad Safari実機の録音、長尺データやオフラインの安定動作は今後確認が必要です。


## Music Atelier ↔ Voice Atelier v0.3.5 連携
「Music連携ZIPを取り込む」から Music Atelier が書き出した無圧縮ZIPを読み込みます。
ZIPの中身は `bridge.json`、`accompaniment.wav`、任意の `melody.wav` です。
`bridge.json` 例:
```json
{
  "format": "music-voice-bridge",
  "version": 1,
  "title": "Song",
  "projectId": "optional-id",
  "bpm": 120,
  "beats": 4,
  "audioFile": "accompaniment.wav",
  "guideFile": "melody.wav",
  "sections": [
    {"name": "Intro", "lyrics": "", "startBeat": 0, "bars": 4},
    {"name": "Verse", "lyrics": "歌詞", "startBeat": 16, "bars": 8}
  ]
}
```
WAVは曲の0秒を先頭とし、無音のイントロも含めます。ZIPは圧縮方式STORE（無圧縮）、各WAVは200MB以内、15分以内です。
伴奏とメロディーガイドは別々のガイドトラックに入り、ボーカルのみの書き出しから除外されます。
録音後「Music Atelierへボーカル連携ZIP」で、`bridge.json`（`format: voice-music-bridge`, `version: 1`, `audioFile: vocals-0sec.wav`, `startSeconds: 0`）と `vocals-0sec.wav` を書き出します。
Music Atelier側にもこの形式のインポート機能が必要です。現時点ではMusic Atelier実機での相互運用は未検証です。
