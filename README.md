# Voice Atelier Song Studio v0.3.1 — Melody Atelier連携と15分音声取り込み

iPad Safari向け、無料のボーカル録音・構成・ミックスWebアプリ。Netlify不要。保存データはIndexedDB（その端末・そのブラウザーの同じURL）に置き、アプリから外部に歌声を送信しません。

## Melody Atelierとの連携（新機能）

1. **まず現在の曲を「↓ プロジェクト一式ZIPで保存」でバックアップ**。連携読み込みは今の曲を置き換えます。
2. Melody Atelier **v0.4.0以降**で「↗ Voice Atelierへ渡すZIP」を使って連携用ZIPを作ります。
3. このアプリのタイムラインにある **「↗ Melody連携ZIPを取り込む」** から、連携ZIPを選択し、確認に同意します。
4. 歌詞、曲名、ブロック構成と開始位置、BPM、拍子が同期。メロディーガイドが「♪ メロディーガイド」という専用レイヤーに取り込まれます。
5. 他の声レイヤーでハモリやリードを録音。再生時はガイドと一緒に聴けます。
6. 完成WAVの書き出しは通常 **ガイドを含めず歌声だけ**。ガイド込みにする場合は「ガイド音声も完成WAVに混ぜる」をONにします。バックアップZIPにはガイドも含まれます。

**制約**：メロディーガイドは音声であり、このアプリで1音ずつ編集する機能はありません。編集はMelody Atelierで行い、再び連携ZIPを書き出してください。その際はVoiceで歌声ZIPをバックアップし、Voice側の連携読み込みが既存録音を置き換えることに注意してください。今のバージョンは既存の歌声を保持したまま新しいガイドだけを再同期する機能はありません。

## 音声時間とファイル形式

- **通常の音声ファイル取り込み：最大15分（1ファイル200MB以内）。** 対応コーデックはSafariが解読できる音声形式に依存します。音声ファイルは選択したブロック/声レイヤーに追加。
- **連携メロディーガイド：最大15分、WAV（200MB以内）、連携ZIP全体230MB以内。**
- **録音：1テイク最大3分（従来通り）。** 区間別の録音はブロック終了時に自動停止も可能。
- **曲全体の書き出し：最大15分、24bit WAV（44.1kHz等、利用端末のAudioContextサンプルレート）。**
- 4つの初期声レイヤーと追加声レイヤー、最大24レイヤー／160クリップ（設定上の数値でありiPadで安定動作する保証はありません）。
- **プロジェクトZIP復元：最大650MB。** プロジェクトに複数の長尺録音がある場合、バックアップ・復元はブラウザーのメモリや容量の制約を受けることがあります。

**品質と保存の注意**：長尺WAVのデコード、エフェクト、書き出しは大きなメモリを使用します。15分すべてをiPad実機で録音・再生・書き出しできることは現時点で未検証です。書き出し前にプロジェクトZIPを保存し、端末の空き容量を十分確保してください。高品質録音はマイク、環境、端末のサンプリング設定にも左右されます。

## 導入・更新（Netlify不要）

GitHub Pagesの公開リポジトリ `Voice-Atelier-Song-Studio` にZIP**内の** `index.html`, `app.js`, `styles.css`, `capture-worklet.js`, `sw.js`, `manifest.webmanifest`, `icon.svg` を配置。更新前は必ずプロジェクトZIPをバックアップしてください。GitHubに公開されるのはソースファイルで、録音や歌詞は明示的にアップロードしない限り公開されません。同じURLなら端末の自動保存を引き継ぐ設計です。初回HTTPS接続時はネット環境が必要です。

左側の歌詞パネルと右側の録音/ミックスパネルは独立スクロールに対応しています。iPad Safari実機の録音、長尺データやオフラインの安定動作は今後確認が必要です。
